# Nexora Digital — Agency Website Concept

A responsive digital-agency concept website built with semantic HTML, CSS and vanilla JavaScript.

## Features
- Responsive desktop, tablet and mobile layouts
- Accessible mobile navigation with expanded-state announcements
- Services, work concepts, about, approach and contact sections
- Keyboard-visible focus styles and reduced-motion support
- Dynamic footer year

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Project notes
Nexora Digital is a fictional studio brand created for frontend portfolio practice. The three work examples (Lumen Studio, North Supply and Form Wellness) are illustrative concepts, not client commissions. The contact section links to the developer's GitHub profile; no real agency contact address is claimed.

## Technologies
HTML5 · CSS3 · Vanilla JavaScript
