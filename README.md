# Nexora Digital — Agency Website

A responsive digital agency concept website built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive desktop, tablet and mobile layouts
- Mobile navigation menu
- Services, work concepts, about, approach and contact sections
- Semantic HTML and accessible navigation labels
- JavaScript menu interaction and dynamic footer year

## Run locally
Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Customize before publishing
- Replace `hello@nexoradigital.example` with your real contact email.
- Update the brand name and copy if you want to use another identity.
- The three project cards are illustrative concepts, not client commissions. Keep that distinction clear in your portfolio.

## Technologies
HTML5 · CSS3 · JavaScript
